## Included source

The previous release PR #2 is merged. This follow-up includes the mobile capsule action menus, 44-pixel touch targets, safe-area viewport, preview cancellation/singleton handling, native-dialog keyboard guards, and automatic closing of mobile navigation after selecting a team or saved view. The title editor resizes after viewport changes, not only after typing.

The review identified needless ResizeObserver allocation on each title keystroke. A stable resize callback now serves a single mounted width observer and a separate value-driven layout effect. Regression tests instrument title observations during typing and resizing. The picker listbox now receives its accessible name directly from the shared picker label, with a Storybook assertion. The final review also enforces the 44-pixel minimum width for short property values and removes a redundant typing-observer scenario without dropping the stronger typing-plus-resize regression.

## Production routing correction

The first post-promotion smoke exposed a platform-only issue-list failure: the named `:path*` rewrite capture was implicitly appended to API query strings. The strict issue-filter validator correctly rejected this unexpected `path` parameter. The API routing pattern now uses an unnamed `/api/(.*)` capture. No filter schema, authentication or application request parser was relaxed.

Vercel CLI 59.16.0's installed official routing compiler was executed for both configurations: the old form produced `/api/index?path=$1`; the new form produces `/api/index` with no injected query. Three regression tests pin capture-free routing/order, actual authenticated synthetic issue filtering and rejection of a genuinely client-supplied `path` filter. Production availability must be verified after promotion on both `/api/v1/issues` and `/api/v1/issues?limit=100`, not only `/api/ready`. See Vercel's primary documentation: https://vercel.com/docs/routing/rewrites .

A separate exact `/api` rewrite preserves the bare API namespace; it must not depend on an empty wildcard or fall through to the SPA. The regression also covers `/api/` and rejects similarly named non-API paths. The final full unit suite contains 153 tests.
